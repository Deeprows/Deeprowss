# Deeprowss

Static first version of the Deeprowss website for GitHub Pages.

## Files

- `index.html` — homepage
- `style.css` — responsive design
- `script.js` — mobile menu, search, and external embed modal

## Customize

Search for `PASTE-YOUR-EMBED-URL-HERE` in `index.html` and replace it with an authorized external embed URL.

The site is intentionally static, so it can run on GitHub Pages without PHP or MySQL.
